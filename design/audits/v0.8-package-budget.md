# v0.8 M0 Package Budget

Date: 2026-09-23

## Web export

| Artifact | Bytes | MiB |
|---|---:|---:|
| Committed v0.7 `docs/index.pck` | 3,816,264 | 3.640 |
| Local M0 `build/web/index.pck` | 3,849,272 | 3.671 |
| M0 delta | 33,008 | 0.031 |
| WebAssembly runtime | 39,514,754 | 37.684 |
| Complete uncompressed Web directory | 43,699,820 | 41.675 |

The PCK increased by 0.86%. It remains 3,490,760 bytes below the M0 ceiling of
7 MiB, leaving 52.4% of that stage allowance in use and 47.6% available.

The WebAssembly runtime is tracked separately because it is the engine payload
rather than game-content growth. Future release reporting must still record
the complete compressed network transfer from the deployed host.

## Export hygiene

The release export excludes:

- design documents and visual receipts
- QA and art tools
- deterministic tests and fixtures
- editable source assets
- generated metadata receipts
- the generated `BUILD_HASH.txt`

The final export log contained no `res://design/`, `res://tools/`, or
`res://tests/fixtures/` entries.

## Texture proof

Godot's ETC2/ASTC import option is enabled in the project and Web preset.
`tools/qa/fixtures/compression_probe.png` is deterministically generated,
configured with `compress/mode=2`, imported as a VRAM texture, and verified to
produce an ETC2 artifact. QA fixtures and their import payloads are excluded
from release exports.

Current v0.7 art remains lossless where its import settings request lossless
compression. Production v0.8 High/Low atlases will be required to pass the same
VRAM/ETC2 verification before entering a package.

## Verdict

PASS. M0 is below its PCK ceiling, the export filter removes nonshipping
material, the production Web build rejects the QA benchmark query, and the
mobile texture-compression path is proven end to end.
