# Generated presentation assets

Files under this directory are deterministic project assets generated by:

- `tools/generate_visual_assets.py`
- `tools/generate_audio_assets.py`

Each output folder contains a manifest with byte sizes and SHA-256 hashes.
Regenerating with the committed scripts must reproduce the same hashes.

The generators use only Python's standard library and contain no external
images, recordings, samples, impulse responses, or instrument libraries.
