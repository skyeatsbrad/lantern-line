# Bundled fonts

The Lantern Line bundles these fonts from the Google Fonts repository at
commit `e44c4b011a820c2cbe2fd2cfa8052037d7edb571`.

| Font | Files | License |
|---|---|---|
| Atkinson Hyperlegible | Regular, Bold | SIL Open Font License 1.1 |
| Bitter | Variable upright | SIL Open Font License 1.1 |

The complete license texts are included as `OFL-Atkinson.txt` and
`OFL-Bitter.txt`.

Atkinson Hyperlegible is the interface/body font. Bitter is reserved for
display headings and title treatments.
